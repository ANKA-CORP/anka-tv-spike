# anka-tv-spike

A throwaway TizenBrew module for our own Samsung TV: does a Kick HLS stream play, and how (native `<video>`, hls.js, AVPlay)? Public only because TizenBrew loads modules through jsDelivr. Will be deleted after the test.

Add in TizenBrew's Module Manager: `ANKA-CORP/anka-tv-spike@main` (GitHub)
